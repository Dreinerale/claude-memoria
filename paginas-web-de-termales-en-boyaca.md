# Páginas web para los negocios de termales de Boyacá

El usuario le está armando páginas web a varios negocios de aguas termales de
la zona de Zetaquirá, Boyacá (Termales Arco Iris, Termales El Ocho, Hotel
Chibchacum, entre otros). Al revisar la propuesta de Termales El Ocho dejó dos
correcciones que valen para todos estos proyectos.

## Se llaman «termales», no «pozas»

Sus palabras fueron: «No se llaman las pozas, se llaman termales». En la región
el nombre del producto y de cada piscina de agua caliente es *termal* —«las
termales», «la termal alta»—, y llamarlas «pozas» suena ajeno al negocio. Hay
que usar el vocabulario con el que el negocio se nombra a sí mismo, tanto en
los títulos y menús como en los textos corridos.

## Cada cliente necesita un diseño propio

Pidió cambiar una sección porque «es parecido al estilo que usamos para el
hotel Chibchacum». Como le está presentando estas páginas a negocios vecinos,
que compiten entre sí y que probablemente vean el trabajo del otro, dos
propuestas que se parezcan delatan que salieron de la misma plantilla y le
restan fuerza a la venta. Cuando se arranque una página nueva para un negocio
de este grupo, hay que cambiar de verdad la tipografía, la paleta y sobre todo
la estructura de las secciones respecto a las páginas ya entregadas, aunque la
referencia visual que él dé sea la misma para todas.
